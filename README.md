# シンプル ToDo リスト

依存ライブラリなしの、HTML / CSS / バニラ JavaScript だけで作ったシンプルな ToDo リストアプリです。
**PWA 対応**で、Android スマホのホーム画面にアプリとしてインストールできます。

## 特徴

- ✅ タスクの追加 / 完了切り替え / 削除
- 📅 期限（いつまでに）の入力
- 🔥 今日が期限のタスクを上部に独立表示
- ↕️ 期限の早い順に自動ソート（期限なしは最下部）
- 🗂️ 未完了（左）/ 完了（右）の2カラム表示
- 💾 `localStorage` による自動保存（リロードしても消えない）
- 📱 PWA 対応（ホーム画面に追加・オフライン動作）
- 🚀 ビルド不要

## 使い方（PC）

`index.html` をブラウザで開くだけです。

## Android スマホで使う

PWA のインストール（ホーム画面追加）とオフライン動作には、
**`https://` または `localhost` でアクセスする**必要があります（ブラウザの仕様）。
リポジトリを公開せずスマホで使う場合の方法は次のとおりです。

### 方法A: 端末内でローカルサーバーを立てる（インストール可能・推奨）

1. スマホにファイル一式（このフォルダ）をコピーする
2. [Termux](https://f-droid.org/packages/com.termux/) をインストールし、フォルダ内で次を実行:
   ```bash
   pkg install python
   python -m http.server 8000
   ```
3. Chrome で `http://localhost:8000` を開く
4. メニュー →「アプリをインストール」または「ホーム画面に追加」

`localhost` はセキュアな環境として扱われるため、Service Worker が有効になり、
インストール後はサーバーを止めてもオフラインで起動できます。

### 方法B: ファイルをそのまま開く（手軽・インストールなし）

ファイルをスマホにコピーし、ブラウザで `index.html` を直接開きます。
通常の Web ページとして全機能が使えます（データも `localStorage` に保存）。
ただし `file://` ではホーム画面へのアプリインストールはできません。

> 💡 もし将来 `https://` のホスティング（GitHub Pages / Netlify など）に置けば、
> 「ホーム画面に追加」だけで本物のアプリのようにインストールできます。

## ファイル構成

| ファイル             | 役割                             |
| -------------------- | -------------------------------- |
| `index.html`         | 画面のマークアップ               |
| `style.css`          | スタイル                         |
| `app.js`             | ロジック（保存・描画など）       |
| `manifest.json`      | PWA の設定（名前・アイコンなど） |
| `service-worker.js`  | オフライン用キャッシュ           |
| `icons/`             | アプリアイコン（192/512px）      |

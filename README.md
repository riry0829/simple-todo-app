# シンプル ToDo リスト

依存ライブラリなしの、HTML / CSS / バニラ JavaScript だけで作ったシンプルな ToDo リストアプリです。

## 特徴

- ✅ タスクの追加 / 完了切り替え / 削除
- 💾 `localStorage` による自動保存（リロードしても消えない）
- 🧹 完了済みタスクの一括削除
- 📱 レスポンシブ対応
- 🚀 ビルド不要 — `index.html` を開くだけ

## 使い方

`index.html` をブラウザで開くだけです。

```bash
# 例: ローカルサーバーで開く場合
python -m http.server 8000
# → http://localhost:8000 にアクセス
```

## ファイル構成

| ファイル     | 役割                       |
| ------------ | -------------------------- |
| `index.html` | 画面のマークアップ         |
| `style.css`  | スタイル                   |
| `app.js`     | ロジック（保存・描画など） |

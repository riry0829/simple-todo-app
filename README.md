# シンプル ToDo リスト

依存ライブラリなしの、HTML / CSS / バニラ JavaScript だけで作ったシンプルな ToDo リストアプリです。
**PWA 対応**で、Android スマホのホーム画面にアプリとしてインストールできます。

## 特徴

- ✅ タスクの追加 / 完了切り替え / 削除
- 📅 期限（いつまでに）の入力
- 🔥 今日が期限のタスクを上部に独立表示
- ↕️ 期限の早い順に自動ソート（期限なしは最下部）
- 🗂️ 未完了（左）/ 完了（右）の2カラム表示
- 💾 `localStorage` による自動保存（リロードしても消えない）
- ☁️ Google Drive 同期（PC・スマホでタスクを共有）
- 📱 PWA 対応（ホーム画面に追加・オフライン動作）
- 🚀 ビルド不要

## 使い方（PC）

`index.html` をブラウザで開くだけです。

## Android スマホで使う

PWA のインストール（ホーム画面追加）とオフライン動作には、
**`https://` または `localhost` でアクセスする**必要があります（ブラウザの仕様）。
リポジトリを公開せずスマホで使う場合の方法は次のとおりです。

### 方法A: 端末内でローカルサーバーを立てる（インストール可能・推奨）

1. スマホにファイル一式（このフォルダ）をコピーする
2. [Termux](https://f-droid.org/packages/com.termux/) をインストールし、フォルダ内で次を実行:
   ```bash
   pkg install python
   python -m http.server 8000
   ```
3. Chrome で `http://localhost:8000` を開く
4. メニュー →「アプリをインストール」または「ホーム画面に追加」

`localhost` はセキュアな環境として扱われるため、Service Worker が有効になり、
インストール後はサーバーを止めてもオフラインで起動できます。

### 方法B: ファイルをそのまま開く（手軽・インストールなし）

ファイルをスマホにコピーし、ブラウザで `index.html` を直接開きます。
通常の Web ページとして全機能が使えます（データも `localStorage` に保存）。
ただし `file://` ではホーム画面へのアプリインストールはできません。

> 💡 もし将来 `https://` のホスティング（GitHub Pages / Netlify など）に置けば、
> 「ホーム画面に追加」だけで本物のアプリのようにインストールできます。

## Google Drive 自動同期のセットアップ

PC とスマホで同じ Google アカウントにログインすると、タスクが自動で同期されます。
データは Drive の**アプリ専用の隠しフォルダ**に保存され、通常のファイル一覧には現れません。

> 同期は `https://` または `localhost` でのアクセス時のみ有効です（OAuth の仕様）。
> PC・スマホとも `http://localhost:8000` で開く運用が簡単です。

### 1. OAuth クライアント ID を発行（一度だけ・無料）

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成
2. 「API とサービス」→「ライブラリ」で **Google Drive API** を有効化
3. 「OAuth 同意画面」を構成
   - User Type: **外部**
   - アプリ名・メールを入力
   - **テストユーザー**に自分の Google アカウントを追加
4. 「認証情報」→「認証情報を作成」→ **OAuth クライアント ID**
   - アプリケーションの種類: **ウェブアプリケーション**
   - **承認済みの JavaScript 生成元** に `http://localhost:8000` を追加
   - （リダイレクト URI は不要）
5. 表示された **クライアント ID** をコピー

### 2. アプリに設定

`config.js` を開き、コピーした ID を貼り付けます。

```js
window.GOOGLE_CLIENT_ID = "あなたのクライアントID.apps.googleusercontent.com";
```

### 3. 使う

1. PC・スマホとも `http://localhost:8000` でアプリを開く
2. 「🔗 Google Drive と同期」をタップし、**同じ Google アカウント**でログイン
3. 以後、タスクの変更は自動で同期されます（「🔄 今すぐ同期」で手動同期も可能）

### 同期が走るタイミング

自分の変更を送るだけでなく、**相手端末の変更を取りに行く**きっかけも用意しています。

- タスクを追加・完了・削除した約1.2秒後
- アプリを開いたとき／別アプリから戻ってきたとき
- 画面を表示している間、1分ごと
- オフラインからオンラインに復帰したとき
- 「🔄 今すぐ同期」を押したとき

送れなかった変更は「未送信」として端末に記録され、次に同期できたときに必ず送られます
（ログイン切れやオフラインをまたいでも失われません）。

### ステータス表示の意味

| 表示                       | 状態                                                     |
| -------------------------- | -------------------------------------------------------- |
| ✅ 同期済み hh:mm          | 正常。両端末が同じ内容になっている                       |
| ⏳ 未送信の変更あり        | 送信待ち。まもなく自動で送られる                         |
| 🔑 再ログインが必要です    | アクセス権の有効期限切れ。ボタンをタップして再ログイン   |
| 📴 オフライン              | 通信なし。変更は端末に保持され、復帰時に送られる         |
| ⚠️ 同期に失敗: …           | 通信・API エラー。変更は保持されるので次回に再送される   |

> **⚠️ 1時間ごとに再ログインを求められる場合**
> Google のアクセストークンは1時間で失効します。通常は裏側で自動更新されますが、
> ブラウザのサードパーティ Cookie がブロックされていると自動更新に失敗し、
> 「🔑 再ログインが必要です」が出ます。その場合はボタンを1回タップしてください。
> （旧版では、この状態でも見た目に出ず、変更が送信されないまま放置されていました）

## ファイル構成

| ファイル             | 役割                                   |
| -------------------- | -------------------------------------- |
| `index.html`         | 画面のマークアップ                     |
| `style.css`          | スタイル                               |
| `app.js`             | ロジック（保存・描画など）             |
| `config.js`          | Google Drive 同期の設定（クライアント ID） |
| `drive-sync.js`      | Google Drive 同期処理                  |
| `manifest.json`      | PWA の設定（名前・アイコンなど）       |
| `service-worker.js`  | オフライン用キャッシュ                 |
| `icons/`             | アプリアイコン（192/512px）            |
